# 长文与 DOCX 工作流

本文件用于长论文、DOCX 输出、批次管理和最终复扫。

## 分批处理

- 先按章节、标题样式或二级标题建立批次，不按固定字数硬切。
- 摘要、英文摘要、绪论、结论、建议、不足与展望单独成批，不能和正文低风险段落混在一起。
- 正文章节按二级标题或自然段落组分批，每批优先控制在 8-15 个正文段落。
- 若某一章红黄段落密集，把该章拆成更小批次。
- 每批开始前列出段落序号、章节名、初判颜色和命中的风险特征。
- 每批应保持语义连续，避免把一个方法说明、数据解释或结论链条拆到两个互不相连的批次。

## 覆盖率台账

长论文必须维护段落级台账，至少记录：

- 批次编号
- 段落序号范围
- 所属章节
- 第一轮风险等级
- 命中特征
- 是否命中报告
- 采用的改写方法
- 是否整段重写
- 批次内是否完成复扫
- 第二轮风险等级
- 是否完成二改
- 问题摘要

台账应持久化为 Markdown 文件，默认命名为 `处理台账.md`，与输出 DOCX 放在同一目录。跨会话继续处理时，先读取已有台账，确认上一批的段落范围、复扫结果和未解决问题，再继续下一批。

只有红色段落和黄色段落都被处理并复扫后，该批次才算完成。

## 批次内复扫

每一批改完后立刻复扫：

- 原红色段落是否仍保留长句骨架、连接词顺序或空泛价值判断。
- 原黄色段落是否至少改变了句序、主语视角、标点节奏或论证落点。
- 同一批中是否出现新的统一模板，如连续使用“这说明”“可以看出”“在此基础上”。
- 连续 3 句同构、连续段落开头同构、相邻句长过于接近等试验性定位信号是否仍集中存在。
- 术语密集窗口是否已经通过分流、限定说明或句式扰动降低风险。
- 专业术语、数据、图表编号和引用编号是否被误改。

如果批次内仍有 2 个以上段落保留明显模板骨架，必须回炉该批。

## 跨批次复扫

全部批次完成后横向比较：

- 各章开头和结尾，避免相同起句和收束句。
- 数据解释段，避免全篇反复使用“表明、说明、可见、相吻合、相对应”。
- 方法和模型说明，避免每个方法都写成“具有优势、能够提升、为后续奠定基础”。
- 结论和建议，避免连续出现“应加强、应优化、应提升、应完善”。
- 各章句长节奏、短句比例和改写手法，避免整篇呈现同一种新模板。

## DOCX 保格式

处理 Word 文档时：

1. 抽取非空段落，跳过目录、参考文献、纯表格数据、页眉页脚和明显不宜改写的编号内容。
2. 若有报告，先定位报告命中片段；若有通过样本，先提炼样本规律。
3. 替换段落文本时尽量保留原段落 style、基础字体、字号、加粗、缩进和行距；复杂 run 级格式、斜体、下划线、上标/下标、颜色、高亮、超链接、脚注、批注、修订痕迹等必须人工复核。
4. 输出新文件后，比对原文和新文档的段落数、表格数、分节数、页边距、页眉页脚距离。
5. 如原文有批注或修订痕迹，不能静默丢失；无法保留时在清单中说明。
6. 如果改写后导致页面明显溢出，优先缩短被改写段落，而不是改变排版。
7. 只打碎修辞性列举编号；章节号、图表号、公式号、引用编号、目录、参考文献、问卷题号、量表条目、附录编号、法律条款等语义编号必须保留。

## 最终自检

输出前确认：

- 试验性定位指标只用于红黄绿定位，没有写成平台官方阈值或通过承诺。
- 专业术语、数据、图表编号、参考文献编号和已有引用未被误改。
- 没有新增没有依据的事实。
- 报告命中片段已经逐段定位并处理。
- 摘要、绪论、研究内容、文献综述、方法、结果、建议、结论等高风险章节已经复扫。
- 数据句、模型句、结论句不再大面积保留整齐模板。
- 没有连续 3 句明显同构；跨段落开头句没有连续使用同一结构。
- 术语密集段已经通过拆分、分流或限定说明降低堆叠感。
- 全文短句、长句和中等长度句有自然波动，没有形成统一拆句模板。
- DOCX 输出没有破坏原格式和排版。
