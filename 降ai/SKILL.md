# 降 AI

## 方法论根基：PDCA 戴明环

本 skill 的核心不是一堆改写技巧的堆砌，而是以 **PDCA（Plan-Do-Check-Act）戴明环**为骨架的持续改进系统。处理论文时，先用小步改写验证判断，再用复扫结果决定是否扩大改动；有效做法进入台账，无效做法停止机械复用。

### PDCA 哲学

> 戴明环的本质不是"检查-修正"的线性流程，而是**阶梯式上升的学习循环**：每一个循环都要产生可观察的改动、检查结果和经验记录。有效做法再标准化，无效做法回到问题原因重新判断。

### 三层嵌套 PDCA（大环套小环）

```
全文 PDCA（大环）
  └→ 章节 PDCA（中环）
       └→ 段落 PDCA（小环）← 核心执行单元
```

- **小环（段落）**：每一段的 P→D→C→A，C 不通过即回炉
- **中环（章节）**：一章内所有段落通过后，横向比较整章风格，检查统一模板
- **大环（全文）**：所有章节通过后，全文扫描跨章节一致性，输出最终文档

### 阶梯式上升原则

每次回炉不能只是"换几个词再试一次"。必须：
1. **5 Why 根因分析**：这段为什么被标记？→ 因为保留了"围绕……展开"句式 → 为什么保留？→ 因为我只改了动词没改结构 → 为什么？→ 因为没检查句式骨架 → **根因：C 阶段没核对句式清单**
2. **换方法组合**：上次用了方法 1+2，回炉时先判断失败原因，再调整方法、力度或适用范围
3. **不机械复用失败路径**：如果一种组合在上一轮失败，下一轮不能原样照搬；只有确认问题不在该方法本身时，才可带着修正条件继续使用

### SDCA 标准化循环

当某条改写策略在多次 PDCA 中被验证有效后，将其固化为后续处理经验。每次降 AI 任务结束后，如果发现了新的有效模式，应在处理台账中说明；只有用户明确要求更新 skill 时，才写入 SKILL.md。

## 适用边界

适用：中文课程论文、毕业论文、研究报告的表达自然化、结构去模板化、DOCX 段落级辅助改写。

不适用：承诺通过任何 AIGC 检测平台、伪造原创性、改写参考文献条目、替用户新增无依据事实、对法律/医学/金融等高风险事实做无来源改动。

所有检测信号只作为**经验性定位规则**，不代表任何平台官方机制、阈值或通过承诺。

## 核心原则

- 保留事实、术语、模型名、数据、图表编号、参考文献编号和原意
- **彻底改变句子骨架**，不能只换词（保留骨架 = 保留 AI 指纹）
- **适度调节信息密度**：功能词、限定语、主语补足、句式拆分或合并都只是候选手段，不设固定比例；以语义自然、学术语体和事实不变为准
- **打破机械整齐结构**：重点处理修辞性编号、排比、对称和同构句式；章节、图表、公式、引用、量表、问卷、附录、法律条款等语义编号必须保留
- 平台风险判断只使用**经验性/试验性定位信号**：句长均匀度、句法重复率、信息密度、模板词频和跨段落同构等，不写成官方阈值
- **退出标准**：风险信号减少、表达自然、事实安全、格式未明显破坏；不承诺任何平台检测结果

### ⭐ 分散替换原则（实证验证——20%→目标的关键）

**核心发现**：平台检测的不是特定词，而是词的**统计分布异常**。全篇统一替换 `A→B`，只是把 A 的统计异常转移给 B。

**必须遵守的轮换规则**：

1. **每个模板词准备 ≥3 个替换词**，跨段落轮换使用，同一替换词在全文出现 ≤5 次
2. **功能词轮换注入**：不全文统一用"已经/比较/更加"，建立功能词池，每段从不同子集选取
3. **替换词的替换词也要轮换**：如果全文统一用"形成"替换"构建"，"形成"本身就会变成新的统计高峰
4. **轮换验证**：改完后全文搜索高频替换词（形成/已经/比较/借助/进一步），任一出现 >8 次即需分散

| 原词 | 替换池（≥3选1，跨段轮换） |
|------|--------------------------|
| 构建 | 形成 / 建立 / 搭建 / 搭起 / 做出 |
| 通过 | 借助 / 利用 / 经由 / 以……方式 / 靠 / 在……中 |
| 提升 | 改善 / 提高 / 拉动 / 推动……往上 / 让……更好 |
| 说明 | 反映出 / 看得出 / 意味着 / 指向 / 从中可以看到 |
| 进一步 | 更加 / 更深一层 / 在更大程度上 / 继续 / 接着 |
| 已经(功能词) | 已 / 早已 / 已然 / 就 / 便 |
| 比较(功能词) | 较 / 相对 / 还算 / 还算得上 / 有一定程度的 |

## 一、小环：段落级 PDCA（核心执行单元）

每个段落必须完整走完以下四步。**不允许跳过任何一步**。

### P — Plan（规划，改写前）

**⚠️ 前置步骤（不可跳过）：解析 AIGC 检测报告。**
- 如果用户提供了 AIGC 统计报告（HTML），必须先解析报告，提取所有被标记的文本片段
- 将报告命中片段映射到原文段落，标记为"报告命中"（最高优先级）
- 报告命中段落优先处理；先根据命中原因选择必要方法，复扫仍高风险时再进入下一轮 PDCA
- 从报告命中的文本中反向提取经验信号：本段到底集中暴露了哪些模板、句法或密度问题？
- 如果用户提供了未通过版本和通过版本，先按 `references/risk-signals.md` 的"通过样本对照"提炼规律，再作为本次方法选择的补充依据
- 如果用户没有提供报告，则仅使用 8 类高危模式扫描

对当前段落执行 **5W2H 分析** + **8 类高危模式扫描**：

**5W2H 快速定位**：
- **What**：这一段在说什么？（定义/论证/数据解释/过渡/总结）
- **Why**：这段为什么可能被报告或经验规则标记？（对症下药）
- **How**：这段需要哪些方法？（普通段落先选 1-3 个主方法；高风险段落可增加辅助方法）
- **How much**：这段需要多大改动力度？（整段重写/局部重组/微调）

**8 类高危模式扫描（逐项勾选）**：

| # | 高危模式 | 检查词/信号 | 本段有无？ |
|---|---------|-----------|----------|
| P1 | 骨架模板句 | "围绕……展开""以……为……""通过……实现……""具有……等优点""呈现出……趋势" | |
| P2 | 框架 | 搜索"框架" | |
| P3 | 整齐编号结构 | "（1）（2）（3）""第一/第二/第三""首先/其次/再次/最后""一是/二是/三是""一方面/另一方面" | |
| P4 | 教科书定义句 | "XX 是指""即""所谓 XX 是""XX 的定义是" | |
| P5 | 模板总结词 | "总体来看""整体来看""综上所述""由此可见""总的来说" | |
| P6 | 句长均匀 | 连续 3 句长度相差 <8 字，或全段都是 20-30 字中等句 | |
| P7 | 术语堆叠 | 约 100 字窗口内术语、模型名、指标名密集出现，且术语间无解释性间隔 | |
| P8 | 英文段落 | Abstract / 英文摘要 | |
| P9 | 数据解释句 | "这说明""表明""可以看出""由此可见""反映"——数据后接解释性判断的句式 | |
| P10 | 学术强化词 | "进一步""更加""更深""更广"——在结论/建议中高频出现 | |
| P11 | 方法描述词 | "通过……（方式/平台/手段/途径）"——同一句型跨段重复 | |
| P12 | 替换产物 | 改写后全文搜索"形成""已经""比较""借助"——任一 >8 次即标记为"引入新模板" | |
| P13 | 提升类动词 | "提升""改善""增强""优化"——在建议/结论段集中出现 | |

P 阶段输出：本段的**模式清单 + 方法选择**，心智中形成后再进入 D。

### D — Do（执行，改写）

根据 P 阶段的模式清单，从下方方法库中选取对应方法执行改写。**P 阶段标记的每一项都必须有对应方法处理**。

**改写方法库**：

**方法 1：功能词注入**（对应全部模式）
- 动词后加"了""到""过"："使用"→"使用了"
- 名词后加"上""中""下"："在评论中""在平台上的"
- 加入"会""要""可以""能够"："影响"→"会产生影响"
- 加入程度词："比较""更加""非常""特别""稍微"
- 加入语助："来说""来看""来看待"
- 把"X性"展开："全面性"→"覆盖的全面程度"
- 功能词只用于调节过高信息密度，不机械追求数量；如果会造成水化、口语化或事实变形，宁可不用

**方法 2：句式骨架打碎**（对应 P1）
- "围绕……展开"→"对……进行研究/分析"
- "以……为（对象/来源/工具）"→"使用/利用/把……当作"
- "通过……实现……"→"利用……来达到……"
- "构建……框架/体系"→"形成……模式/方式"
- "呈现出……趋势"→"表现为……走向"
- "为……奠定基础/提供支撑"→"给……打下基础/提供支持"

**方法 3：框架替换**（对应 P2）
- "框架"→"模式"/"方式"/"结构"/"路径"（全文交替使用）
- 避免机械高频使用"框架"；必要术语如"理论框架""分析框架"可保留，但要改变周围句式并减少模板化表达

**方法 4：编号结构打碎**（对应 P3）
- （1）（2）（3）→ 去掉编号，改为不规则自然段落，用"在……方面""……上""关于……"引入
- 第一/第二/第三 → 直接分段或用完全不规则的过渡。**禁止用"首先……其次"替换——两套编号都会被检测！**
- 首先/其次/再次/最后 → 完全删除，改为不规则的起句方式
- 一是/二是/三是 → 完全消除
- 一方面/另一方面 → 拆成两个独立句子，不允许保留平行结构
- 只打碎修辞性列举编号；章节号、图表号、公式号、引用编号、目录、参考文献、问卷题号、量表条目、附录编号、法律条款等语义编号必须保留

**方法 5：总结词消除**（对应 P5）
- "总体来看""整体来看""综上所述""由此可见"→删除，直接陈述结论

**方法 6：定义句改写**（对应 P4）
- "XX 是指 YY"→"XX 可以理解为 YY"/"简单说，XX 就是 YY"/拆成两句

**方法 7：英文改写**（对应 P8）
- 打破长句，句长差异明显（相邻句长差 ≥5 words）
- 降低正式度："exhibited a significant positive driving effect"→"had a clear positive effect"
- "is deconstructed into"→"can be broken down into"
- "fills a theoretical gap"→"adds to existing research"
- "the results indicate that"→"from the results,"
- "Consequently," → 删除，直接陈述。减少 "Furthermore/Moreover/Nevertheless/Accordingly"
- "not only...but also..." → 拆成两句，这种平行结构在英文中也属高危
- 段落开头句式要有变化：不要连续两句用 "This study/It/The results" 开头
- 降低过度模板化和过度正式化；保持语法正确、学术自然，不刻意制造错误或非母语痕迹
- 英文段落也需要长短交替：至少 1 句 ≤12 words，至少 1 句 ≥28 words

**方法 8：专名密度调节**（对应 P7）
- 大多数降AI场景下，专名密度**过高**才是问题（术语堆叠 = AI 特征）。此时应：压缩句子长度，术语间插入"以及""还有""等方面的"等口语间隔词，或把术语分散到不同句子中
- 少数情况下专名过少导致段落空洞时：补全主语、条件和限定说明，适当拉长解释
- 判断标准：约 100 字窗口内术语密集且缺少解释时标为风险；结合学科、段落功能和原文事实判断
- 原则：专业术语/数据绝对不改，只改周围的解释语和间隔方式

**方法 9：句号→逗号/分号/破折号**（对应 P6）
- 相邻短句适度合并，用逗号/分号衔接，减少句号密度
- 但要保持段落内有句号——不能全段无句号
- **注意**：此方法不能与方法 10 冲突。合并短句后，必须确保段落内仍有至少一个短句（≤15字）和一个长句（≥35字）。如果合并后全段只剩中长句，则不能使用此方法。

**方法 10：长短句交替**（对应 P6）
- 同一段内句长差异 ≥8 字
- 不允许连续 3 句长度相近（<8 字）
- 长句 35+ 字、短句 15- 字交替

**方法 11：逻辑词减量**（辅助方法）
- 砍掉至少一半的"因此/所以/然而/此外/同时/并且"
- 允许直接并列不加连接词
- **注意**：此方法只砍形式逻辑连接词，不能与方法 1 机械对冲。两者可组合使用，但必须说明目的，避免为了执行方法而加词或删词。

**方法 12：不必要内容删减**（辅助方法）
- 删除不影响论证的套话
- 删除同一意思的重复表达

**方法 13：数据解释句多样化**（对应 P9）
- "这说明" → "这个结果指向……""从中可以看到……""放在一起看，……""换句话说，……"
- "数据表明" → "数据给出的信号是……""按照这个趋势，……"
- 每个数据解释句用不同的起手方式，同一章节内不重复

**方法 14：强化词降级**（对应 P10）
- "进一步" → "接着""继续""更深一步""在更大范围内"
- "更加" → "更为""愈发""进一步地""更深层的"
- 注意：这也是分散替换，不能全文用一种替换

**方法 15：方法句多样化**（对应 P11）
- "通过A方式" → "A是本文采用的一个主要办法""借助A""本文走的是A这条路""靠A来完成"
- "通过B平台" → "在B平台上""依托B""以B为渠道""借助B来"
- 同一章内不重复同一句式

### C — Check（检查，改写后）

改写完成后，**必须逐项核对以下检查项**。任何适用项不通过，该段标记为"未通过"。

| # | 检查项 | 通过标准 | 通过？ |
|---|--------|---------|--------|
| C1 | P1 骨架模板已消除 | 无"围绕展开""以…为…""通过…实现""呈现出…趋势" | |
| C2 | P2 "框架"已处理 | 机械高频的"框架"已替换；必要术语保留并改变周围句式 | |
| C3 | P3 编号已打碎 | 无（1）（2）（3）/第一第二第三/首先其次再次最后/一是二是三是/一方面另一方面 | |
| C4 | P4 定义句已改写 | 无"XX是指""即"定义句式 | |
| C5 | P5 总结词已消除 | 无"总体来看""综上所述""由此可见" | |
| C6 | 信息密度已调节 | 过密段已补足条件、主语或限定说明；过松段已删除空泛填充，未机械加词 | |
| C7 | 句长有节奏 | 至少 1 对相邻句差 ≥8 字，无连续 3 句长度相近 | |
| C8 | 事实安全 | 术语/数据/引用编号/图表编号未被误改，未新增无依据内容 | |
| C9 | P7 术语密度已调节 | 术语密集处已有拆分、分流或限定说明，未误改术语/数据 | |
| C10 | P8 英文已改写 | 英文段落句长差异明显，开头句式有变化，正式度降低 | |
| C11 | P9-P13 新模板词已分散 | 全文"说明"≤4、"进一步"≤5、"通过"≤6、"提升"≤5、"形成"≤5、"已经"≤3、"比较"≤3 | |
| C12 | 替换产物已检查 | 全文搜索改写用替换词（形成/已经/比较/借助/可以理解为），任一 ≤5 次（与分散替换原则统一阈值） | |

**C 阶段附加检查：防止引入新模式。**
改写后的段落必须重新跑一遍 P 阶段的 8 类高危模式扫描，确保没有**新增**任何模式。实证表明，改写过程中容易引入新的 `是指`、`首先/其次` 或平行结构。如果发现新增模式，视为 C 阶段未通过。

### A — Act（处置，修正与标准化）

- **如果 C 阶段全部通过**：该段落完成，标记为"已通过"，进入下一段。
- **如果 C 阶段有未通过项**：
  1. 用 **5 Why** 追问根因（为什么这项没过？→ 因为……→ 为什么？→ ……）
  2. 换方法组合，加大力度（例如：第一次用了方法 1+2，回炉时加方法 4+9+10）
  3. 重新执行 D→C，直到全部通过
  4. 记录：该段的失败模式 + 最终有效的改法 → 作为后续段落的经验

**重要**：如果连续 3 段都因同一个 C 项未通过，暂停，重新读一遍 skill 的方法部分，确认理解正确后再继续。

## 二、中环：章节级 PDCA

一章内所有段落通过小环 PDCA 后，执行章节级检查：

### P（章）：扫描整章
- 列出该章所有段落的 C 阶段结果
- 识别是否有连续的段落使用了相同的改写方法组合

### D（章）：无需额外操作（已在段落级完成）

### C（章）：横向比较
- [ ] 该章内各段开头句是否有变化？（不允许连续 3 段用相同句式开头）
- [ ] 该章内各段结尾句是否有变化？
- [ ] 该章内是否有连续段落形成新的统一模板？
- [ ] 数据解释句是否仍大面积使用"表明/说明/可见/相吻合"？
- [ ] **改写策略有效性回顾**：逐段回看该章使用的改写方法组合——是否有连续 ≥3 段用了完全相同的替换词（如同全文用"形成"替换"构建"）？若有，回到这些段落更换替换词，确保分散轮换。

### A（章）：回炉与标准化

## 三、大环：全文级 PDCA

### P（全文）：设定退出标准
- 全文目标：显著降低 AIGC 风险信号，不承诺任何平台检测结果
- 不可妥协项：事实安全、必要编号安全、适用检查项通过、无明显新模板

### D（全文）：已在章节级完成

### C（全文）：全局关键字扫描 + 跨章节一致性

**全文搜索（以下各项用于定位高频和模板化用法，不作为机械删除命令）**：
- [ ] `围绕` → 检查是否为模板句；必要语义可保留

| 框架 | 模式 / 方式 / 结构 / 路径 |

| 以……为研究对象 | 把……当作研究对象 |

| 为弥补这一缺陷 | 为了解决该问题 |
| 逐渐成为 | 慢慢变成 |
| 推动了……发展 | 带动了……的进一步发展 |
| 系统梳理 | 整体梳理 / 进行了整理 |
| 奠定了……基础 | 打下了……基础 |
| 为……提供依据 | 给……提供依据 |
| （1）……（2）……（3）…… | 拆为不规则自然段，去掉编号 |
| 第一……第二……第三…… | 改为不规则的列举方式 |
| 兼具 A 和 B 属性 | 同时具有 A 和 B 的特点 |

| 通过……实现/完成 | 借助……来达到 / 利用……完成 |
| 具有重要意义 | 有一定意义 / 对……有比较重要的意义 |

### 既有样本对比中观察到的高风险操作（来自 x1→x2 对比分析）

以下操作在既有样本对比中表现较差，作为优先避开的经验规则，不代表平台官方判定机制：
- ❌ `"综上" → "总体来看"` — "总体来看"是 P5 高危模板词，替换后标记反增
- ❌ 全局盲目替换 `"以" → "把"` — "以"有多种词性，盲目替换会破坏语法
- ❌ 用"首先……其次……再次……最后"替代"第一……第二……第三" — 两套编号都会被标记
- ❌ 保留"不仅……而且……"平行结构 — 必须拆成两句
- ❌ 英文摘要仅做词汇替换不改变句式 — 既有样本显示英文摘要的句长均匀度容易成为风险信号
